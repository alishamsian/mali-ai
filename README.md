# پولت

اپ Android مدیریت مالی شخصی برای ایران: ثبت خودکار تراکنش از پیامک بانکی (پردازش فقط روی گوشی)، بودجه، دارایی‌ها و گزارش ماه مالی شمسی.

## پیش‌نیاز

- Node 22 (حداقل 20)
- JDK 17 و Android SDK برای بیلد نیتیو
- فونت Vazirmatn در `assets/fonts`

## نصب و اجرا

```bash
npm install
npx react-native-asset
npm start
npm run android
```

`.npmrc` گزینه‌ی `legacy-peer-deps` را روشن می‌کند (`lucide-react-native` هنوز React 19 را در peer ندارد)؛ بدون آن `npm install` با خطای ERESOLVE متوقف می‌شود.

اگر متن‌ها سمت چپ افتادند، اپ را کامل ببندید و دوباره باز کنید: `forceRTL` قبلی ممکن است روی دستگاه مانده باشد.

## تست و کیفیت

```bash
npm run typecheck
npm run lint
npm test
```

همین سه مرحله در CI (`.github/workflows/ci.yml`) روی هر push به `main` و هر Pull Request اجرا می‌شوند. lint فقط با خطا شکست می‌خورد؛ هشدارهای باقی‌مانده استایل inline هستند.

## بیلد نسخه‌ی انتشار

```bash
npm run apk
```

خروجی در `preview/mali-ai.apk` کپی می‌شود. هنگام هر انتشار `versionName` در `android/app/build.gradle` و `APP_VERSION` در `src/app/config/version.ts` را با هم بالا ببرید.

## همگام‌سازی ابری (اختیاری)

بدون تنظیم Supabase اپ کاملاً آفلاین کار می‌کند و داده‌ها رمزگذاری‌شده روی گوشی می‌مانند.

1. یک پروژه در Supabase بسازید.
2. مایگریشن‌ها را به ترتیب اجرا کنید، یا در SQL Editor داشبورد یا با CLI (`supabase link` و بعد `supabase db push`):
   - `supabase/migrations/0001_init.sql`: جدول‌ها و RLS
   - `0002_sync_category_fk.sql`: حذف کلید خارجی دسته‌بندی
   - `0003_sync_local_payload.sql`: ستون‌های لازم برای بازگردانی کامل
3. در Authentication → Email Templates → Magic Link، کد یک‌بارمصرف `{{ .Token }}` را در متن ایمیل بگذارید (ورود اپ با کد ۶ رقمی است، نه لینک).
4. `.env.example` را به `.env` کپی کنید و مقادیر Project Settings → API را بگذارید:

   ```
   SUPABASE_URL=https://xxxx.supabase.co
   SUPABASE_ANON_KEY=...
   ```

   کلید `service_role` را هرگز در اپ نگذارید. این دو مقدار هنگام بیلد با `scripts/babel-plugin-inline-env.js` در کد قرار می‌گیرند؛ بعد از هر تغییر `.env`، Metro را با `npm start -- --reset-cache` اجرا کنید.

بعد از آن در اپ: تنظیمات → پشتیبان و همگام‌سازی → «حساب ابری». با ورود، همه‌ی حساب‌ها و تراکنش‌ها یک‌بار در صف ارسال قرار می‌گیرند و بعد از آن هر تغییر خودکار ارسال می‌شود. «بازگردانی از ابر» فقط چیزهایی را اضافه می‌کند که روی گوشی نیست.

همگام می‌شود: حساب‌ها و تراکنش‌ها (بدون متن خام پیامک). هنوز همگام نمی‌شود: بودجه، هدف، قانون دسته‌بندی و تنظیمات؛ برای این‌ها از «پشتیبان رمزدار» استفاده کنید.

## گزارش خطا

خطاهای رندر و خطاهای پیش‌بینی‌نشده‌ی JS در یک لاگ رمزگذاری‌شده روی گوشی ثبت می‌شوند (۲۰ مورد آخر). هر صفحه Error Boundary خودش را دارد، پس خطای یک صفحه کل اپ را از کار نمی‌اندازد. کاربر از تنظیمات → راهنما و پشتیبانی → «ارسال گزارش خطا» آن را با منوی اشتراک گوشی می‌فرستد؛ هیچ چیز خودکار از گوشی خارج نمی‌شود.

## وضعیت پارس بانک‌ها

ملت، ملی، سامان، تجارت، پاسارگاد: اسکلت آماده، **منتظر پیامک واقعی** (`NEEDS_FIXTURES`).

پارسر عمومی فقط روی کلیدواژه‌های فارسی (برداشت/واریز/خرید/...) کار می‌کند و ادعا نمی‌کند قالب رسمی بانک است.

## مستندات بیشتر

`docs/`: معماری، پایگاه داده، امنیت، پارسر پیامک، ورود تاریخچه‌ی پیامک و سیستم رابط کاربری.
