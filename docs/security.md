# امنیت

## روی دستگاه

- تراکنش‌ها و حساب‌ها محلی
- متن خام SMS به بک‌اند نمی‌رود
- فقط `patternHash`، `bankId`، نسخه پارس، موفقیت/شکست
- شماره کارت فقط ۴ رقم آخر
- ترجیحات غیرحساس: MMKV
- رازها: Keychain (برای نشست آینده)

## ریموت

- فقط `anon` key در کلاینت؛ هیچ service role در اپ موبایل نیست
- RLS روی تمام جداول مالی
- AI فقط از Edge Function و روی اعداد از پیش محاسبه‌شده

## مجوز SMS

قبل از درخواست مجوز، دلیل توضیح داده می‌شود. Accessibility Service استفاده نمی‌شود.
